# Team/personal "AI work OS" products — research brief

_question: which ready-to-use products implement the AO-Personal-OS / SoftServe shared-work-OS concept (shared team skills, shared context, self-learning, automations) with ready UI, harness, and guardrails — for own-team adoption, client deployments, and personal use?_
_date: 2026-08-15 · sources: 24 (4 parallel verification clusters, ~20 products checked against live vendor docs/pricing) · provenance: (chat)_

## TL;DR
The category exists and is crowded, but **no product ships the whole concept** — the closest are **Claude Team + Cowork** (the productized version of this repo's rig: org-provisioned skills, cloud scheduled tasks, admin guardrails — existing `.claude/skills` carry over as-is), **Dust** (independent "multiplayer agent OS", Claude-capable, self-serve $30/seat), and **Notion Custom Agents** (the only one where agents read *and write* a human-curated workspace with page-history provenance) **[Fact-synthesis, tiers below]**. The benchmark dimension nothing ships is **self-learning** — corrections becoming durable team rules is manual or absent in every product checked **[Fact/absence across all 4 clusters]** — which is both the moat of the hand-rolled OS and the services wedge for the SoftServe Jumpstart/work-OS offering.

## What's known
1. **Claude Team/Enterprise + Cowork is the managed near-equivalent of this repo.** Admins provision Agent Skills org-wide (enabled-by-default, view-only shares that auto-update), plugins bundle skills+connectors+subagents, Cowork runs scheduled tasks in Anthropic's cloud with laptop closed, and enterprise controls include RBAC, per-connector read/write restriction, spend limits, audit logs **[Fact/tier-1: support.claude.com provisioning + scheduled-tasks articles, claude.com/blog/organization-skills-and-directory + /cowork-for-enterprise]**. Cowork GA on all paid plans since Jul 2026 **[Fact/TechCrunch 2026-07-07]**. Gaps vs. benchmark: no provenance-linked curated wiki (Projects + editable team memory only) and self-learning is user-initiated via skill-creator **[Inference from docs]**. Migration cost from this repo ≈ zero: same skills format.
2. **Dust is the strongest independent whole-concept product** — "multiplayer operating system for enterprise AI": shared agents in a no-code builder, permissioned Spaces over 100+ connectors, native scheduled + webhook Triggers, per-agent model choice incl. Claude, granular permissions/audit; $40M Series B May 2026 (Sequoia), >3,000 orgs, self-serve to 100 seats **[Fact/tier-1-2: docs.dust.tt/docs/triggers, dust.tt/blog/agent-operating-system + series-b, tech.eu]**. No self-learning, approval-gates unverified, SaaS-only **[Fact/absence]**.
3. **Notion 3.x Custom Agents (GA 2026-02-24) is the closest structural analog to the repo-as-shared-brain**: shared versioned agent definitions; agents read/write the workspace itself; agent memory stored as inspectable Notion pages (version history = provenance); triggers on schedule, Slack message, incoming email, DB change **[Fact/tier-1-2: notion.com/releases/2026-02-24, matthiasfrank.de custom-agents tutorial]**. Weakest of the top tier on enterprise guardrails (no approval gates/audit console evidenced) **[Fact/absence]**.
4. **OpenAI ships the same shape one tier up**: Workspace Agents (research preview on Business/Enterprise) = team-shared agents with named "skills, memory, schedules, and governance settings" **[Fact/tier-1: openai.com Workspace-Agents post]** — but memory stays personal/project-scoped, and **Frontier** (Feb 2026), the fuller "agents as digital employees" agent-ops platform, is invite-only for Fortune-500 pilots (HP, Intuit, Oracle, Uber) **[Fact/tier-2: CNBC 2026-02-05]**. Agent Builder/AgentKit is deprecated (shutdown 2026-11-30) **[Fact/tier-1: OpenAI community notice]**.
5. **Suite-locked contenders matter only where the client already lives**: M365 Copilot Studio has cluster-best governance (Purview on agents, Agent 365 registry) and an explicit skills architecture — but it GAs only Dec 2026 (Copilot Tuning→Studio transition) **[Fact/tier-1: learn.microsoft.com copilot-tuning-overview]**. Atlassian Rovo bundles agents + the Teamwork Graph into existing paid seats with an org-wide agent inventory **[Fact/tier-2: SiliconANGLE Team '26]**. Glean adds the best knowledge graph + self-host/BYO-LLM (incl. Claude) but is enterprise-sales-only at ~100-seat minimums **[Fact/tier-1 docs.glean.com; pricing 3rd-party]**.
6. **Ruled out**: Sana (absorbed into Workday, Mar 2026 relaunch as Workday's AI layer — roadmap risk) **[Fact/tier-1: Workday IR]**; Manus (unresolved China ownership review after the blocked $2B Meta deal + weakest guardrails) **[Fact/tier-2: Forbes 2026-04-27]**; Writer (Palmyra lock-in, no Claude/BYO) **[Fact/tier-2: TechCrunch 2026-08-13]**; Gemini Enterprise (core capabilities paywalled at $50/seat Plus; twice-renamed line) **[Fact/tier-1-2]**; Zapier Agents (duplicates the n8n harness already running here, at higher cost); Credal (pure governance layer, not a work OS).
7. **The self-learning gap is systemic.** Closest approximations: Claude team memory (auto-learns, editable, no rule-routing), Lindy's draft-approval tone learning (~40 approvals to on-brand, scoped to writing) **[Fact/tier-3 review]**, Notion's curatable agent-memory pages. Nobody automates "correction → generalized rule → routed to the owning skill/context home" — the loop this repo runs by hand **[Fact/absence across clusters]**.
8. **n8n (already running here) now covers harness + approvals + skills-as-subworkflows** — gated tool calls with approve/reject via Slack/email shipped May 2026; sub-workflows attach to AI Agent nodes as reusable tools **[Fact/tier-1: docs.n8n.io human-in-the-loop]** — but shared context and self-learning stay build-it-yourself.
9. **Market signal for the product-leader lens**: the "work OS" is being platformized top-down — OpenAI Frontier (gated), Anthropic's Managed Agents API beta (versioned agent configs, shared memory stores, scheduled deployments, per-tool `always_ask` policies — the benchmark as infrastructure, minus UI) **[Fact/tier-1: platform docs, beta]**. The assembled-product layer on top is where Dust/Notion/startups compete.

## For Alex
- **Own teams (SoftServe R&D / GigaCloud): pilot Claude Team + Cowork.** Existing skills port as-is, org provisioning solves distribution, cloud scheduled tasks replace part of the launchd/n8n legs; aligns with the R&D 2027 bet #4 (Anthropic tier-1 partnership → [softserve](../../areas/softserve/README.md)). Dust is the fallback if multi-model or non-Anthropic client policy blocks Claude-only.
- **Client deployments (Jumpstart / work-OS offerings): pick by client stack, not by category winner** — M365 shop → Copilot Studio (flag the Dec-'26 skills GA), Atlassian shop → Rovo (bundled = easiest procurement), stack-neutral or EU → Dust, governance-led enterprise → Glean. The systemic self-learning gap (pt. 7) is the durable services wedge: products distribute skills, but building the team's context + correction loop is exactly what the Jumpstart "shared AI work-OS" sells → [jumpstart-pm](../../areas/softserve/jumpstart-pm.md).
- **Personal OS: no migration warranted.** Nothing productizes the curated-wiki + self-correction combo (→ prior [context-maintenance brief](context-maintenance-best-practices.md)); the cheap upgrade is adopting Cowork/claude.ai surfaces as UI+harness over this same repo — which the cloud routines already half-do (→ [architecture comparison](agentic-architecture-options-comparison.md)).

## Gaps & caveats
- **All vendor pages were read at one remove** — the sandbox egress proxy blocked direct fetches (claude.com, openai.com, dust.tt, notion.com, learn.microsoft.com…); claims come from search-indexed copies of those exact official URLs. Same 403 pattern as prior briefs; re-verify pricing on the official pages before any purchase.
- Most pricing is 3rd-party-tracker-sourced (flagged in-table); Claude Team seat composition (whether standard seats include Claude Code) had conflicting sources — unverified.
- Fast-moving surfaces: OpenAI Workspace Agents is a research preview; Copilot skills architecture is pre-GA; Notion seat pricing not re-verified this pass. Anything load-bearing needs a re-check at decision time.
- Self-learning verdicts are absence-of-evidence after targeted checks, not proofs of absence.
- Bounded pass (~20 products, 4 clusters): per-product depth is one verification sweep, not a hands-on eval. Before committing a team, a 2-week pilot of the top pick (or `/deep-research` on a 2–3-product shortlist) is the right next step.
