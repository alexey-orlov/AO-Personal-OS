## Top items to study this session

#### 1. 🟡 Missing article (a / an / the) — ~14 instances

You routinely drop the article before a specific referent, especially "agent", "system", "repository". English needs one almost every time here. This is your most frequent and most audible pattern.

- "so that **agent** is able to reference that" → so that **the agent** is able to reference that
- "It's **operating system** that combines skills" → It's **an operating system** that combines skills
- "It's also **repository**, but not of the code base" → It's also **a repository**, but not of the code base

**Drill:** before any noun, ask "specific one we both know → *the*; one-of-many, first mention → *a/an*; only skip both for true plurals/uncountables." Rehearse: *the agent, the system, a repository, a framework, an approach.*

#### 2. 🟡 No "will" after "if" (first conditional) — 4 instances

In real conditionals the *if*-clause stays present tense; "will" goes only in the main clause. "If it *will be*" always sounds non-native.

- "**if it will be** available at least by week 3" → **if it's** available at least by week 3
- "**if you'll be** active there" → **if you're** active there
- "**the more inputs you will provide**" → **the more inputs you provide**

**Drill:** *If X happens, Y will happen.* Will lives on the right side of the comma only. Mental check: hearing "if … will" → delete the "will".

#### 3. 🟡 Wrong preposition in collocation — 6 instances

The verb/noun is right, the preposition attached to it is off.

- "preparing **to** them" → preparing **for** them
- "impact size **in** the feature" → impact size **of** the feature
- "align **[Ø]** how we collaborate" → align **on** how we collaborate

**Drill:** these are memorised, not derived — lock the pairs: *prepare **for**, the size **of**, align **on**, present **to** someone, speak **in** general terms, start **in** week 2.*

#### 4. 🟡 Demonstrative & "kind of" number agreement — 6 instances

"this" + a plural noun, and "is" + a plural subject, must agree; and "kind of" needs care with number.

- "we just set **this basics**" → we just set **these basics**
- "**this is the outputs**" → **these are the outputs**
- "these **kind** of things" → these **kinds** of things (or *this kind of thing*)

**Drill:** singular pair *this/that + is*; plural pair *these/those + are*. For "kind": one → *this kind of thing*; many → *these kinds of things*.

#### 5. 🟡 Verb complementation (suggest / decide / feel / why not) — 4 instances

After certain verbs English wants a specific form, not "to + verb" or a "that"-clause.

- "we **suggest to integrate** the customer feedback" → we **suggest integrating** the customer feedback
- "the artifacts that you **feel to be** the great sample" → the artifacts that you **feel are** great samples
- "**Why not to match** that with the prototype" → **Why not match** that with the prototype

**Drill:** *suggest / recommend + -ing*; *decide + to*; *why not + bare verb*. Quick test: "suggest to do" always wrong → "suggest doing".

#### 6. 🟡 Mangled set-phrases & non-native collocations — ~10 instances

Fixed English expressions that came out slightly rebuilt. Each is understood but flags as non-native.

- "So this OS **comprises of** these three things" → **comprises** / **consists of** these three things
- "**On the contrary to** week 4" → **As opposed to** / **Unlike** week 4
- "But **on the other side**, there is David" → But **on the other hand**, there is David

**Drill:** memorise them whole: *comprises Ø / consists **of***; *on the other **hand***; *as opposed to*; *even **better** (not "more fine")*; *give a demo (not "make")*.

#### 7. 🔴 Run-on / overlong sentences — comprehensibility

Several explanations stack 3–4 clauses so the main point lands late and the listener loses the thread. Break them.

- "…also important from your yesterday's comments, what I see this session will show you and how the system— I expect that you will see that the system helps you in the area of first using the entire context of the feature discovery on the previous stage to create that prototype and supplement it with additional comments for the either designers or developers who are working down the process…" → **"This session shows how the system reuses the full feature-discovery context to build the prototype — and adds comments for the designers and developers downstream, which is where the gap is today."**

**Drill:** one idea per sentence. When you feel a second "and… which… because…" coming, stop, put a full stop, start fresh.

#### 8. 🟡 Indirect-question word order — 2 instances

Inside a statement, the embedded question keeps normal subject–verb order (no inversion).

- "how **is it** different from working with the environment" → how **it is** different
- "you kind of get that understanding of … **where goes what**" → … **what goes where**

**Drill:** *I know how it works* (not "how does it work"). Embedded question = statement order.
