## Top items to study this session

#### 1. 🟡 Wrong preposition in collocation — 6 instances

English fixes the preposition to the verb or noun, and it rarely matches the Russian/Ukrainian one. These are memorised as units, not derived.

- "if you take a look **on** the full documentation" → if you take a look **at** the full documentation
- "access rights **on** the Git level" → access rights **at** the Git level
- "I would suggest starting **from** this one" → I would suggest starting **with** this one

**Drill:** *look at · at the X level · start with · a perspective on · analytics on*. The trap set is the ones where RU uses "на/с": *на уровне* → **at** the level, *начать с* → start **with**.

#### 2. 🟡 Missing article on discourse referent — 5 instances

Once a thing has been introduced (the system, the agent, the customer side), English requires **the** on every later mention. Dropping it is the single most audible RU/UA tell.

- "So **system** has kept context on it" → So **the system** keeps context on it
- "due to the embedded mechanisms that **agent** has" → that **the agent** has
- "split the team **on customer side**" → split the team **on the customer side**

**Drill:** before any bare singular noun, ask "have we met this one already?" — if yes, **the**; if it is the first mention, **a/an**. A bare singular countable noun is almost always wrong.

#### 3. 🟡 Non-native word choice — 5 instances

Each of these is a real English word used slightly outside its actual meaning — the listener understands but registers the mismatch.

- "Let's meet **someday** next week" → Let's meet **sometime** next week
- "what I have locally in my **clone** repository" → in my **cloned** repository / my **local clone**
- "token usage and Git activity **as a tool** that they will use to measure" → **as the metrics** they will use to measure

**Drill:** *someday* = an unspecified day in the distant future ("someday I'll write a book"); *sometime* = at some point in a known window. Also: metrics are **measures**, not tools; *mitigate the rough edges*, never bare *edges*; *internally / inside our own teams*, never *within us*.

#### 4. 🟡 Set-phrase mangled — 3 instances

Fixed idioms have no free slots — a near-miss is more noticeable than a plain error, because the listener recognises the phrase and hears it break.

- "that's another innovation, **so to say**" → that's another innovation, **so to speak**
- "changing the skills **on the go** randomly" → changing the skills **on the fly**
- "here you are, **here you are**, you get that" → **there you have it** / and **there it is**

**Drill:** *so to speak* (not *so to say*) · *on the fly* = improvised, *on the go* = while busy or travelling · *here you are* = handing someone an object, *there you have it* = presenting a result.

#### 5. 🟡 Repetitive scaffolding / circular phrasing — 3 instances

Rebuilding the same clause frame for each list item costs three times the words and makes the list harder to hold. State the frame once, then list.

- "there is a right place for PRDs **to be stored**, there is a right place for relevant metrics **to be stored**, there is a right place for decision log…" → there is **a designated place for each**: PRDs, relevant metrics, the decision log
- "Most of the users, regular product managers, **are just users** able to interact with agents" → Most users — regular product managers — **can only** interact with agents

**Drill:** when you hear yourself start the same clause a second time, stop and convert to a list: "a place for X, one for Y, one for Z."

#### 6. 🟡 Countable/uncountable confusion — 2 instances

*Context* and *feedback* are uncountable in English — no plural, and no article when speaking generally.

- "if you want to pull all the **contexts** related to a particular initiative" → all the **context** related to a particular initiative
- "test and **the feedback** is welcome" → test it, and **feedback** is welcome

**Drill:** uncountables you use daily: *context · feedback · information · research · advice · progress*. Never *-s*, and no *the* when the meaning is general.

#### 7. 🔴 Dummy subject: "There is" used for "It is" — 1 instance

*There is* introduces existence ("there is a problem"). To evaluate something, English needs the dummy **it**. This one lands in the first sentence of the presentation, so it sets the register for everything after.

- "**There is** important to mention that we decided to split the team" → **It is** important to mention that we decided to split the team

**Drill:** *It is important / useful / worth noting that…* — three fixed openers. Reserve *there is* strictly for "X exists".

#### 8. 🟡 Present tense for a planned capability — 1 instance

Saying *we have* about something on the roadmap tells a stakeholder it already ships. Here the same sentence then contradicts itself with "that's part of the roadmap", which is exactly the ambiguity to avoid in front of a client.

- "but we definitely **have** the more granular analytics… that's part of the roadmap" → but we definitely **want to have** / **plan to have** the more granular analytics — that's part of the roadmap

**Drill:** three tiers, keep them separate out loud: *we have it* (shipped) · *we're building it* (in flight) · *it's on the roadmap* (planned).
