## Top items to study this session

#### 1. 🟢 Missing article on a specific or countable noun — 7 instances

A singular countable noun needs *a* or *the*, and a specific thing everyone in the room already knows (the large docs solution, Oracle's packs, the customer) takes *the*. One drop is minor; seven in one meeting make it the most frequent non-native signal in this call (a few may be ASR drops).

- "it's not feasible for **large docs processing solution**" → "it's not feasible for **the** large docs processing solution"
- "we still have **video demo**" → "we still have **a** video demo"
- "we don't use anything from **OCI Accelerator packs** provided by Oracle" → "we don't use anything from **the** OCI accelerator packs provided by Oracle"

**Drill:** before a singular noun, ask "which one?" The one we all know → *the* (*the customer*, *the demo*, *the large docs solution*); any one → *a* (*a Helm chart*, *a real pipeline*, *a video demo*). Only plurals and uncountables in general go bare (*documents*, *data*).

#### 2. 🟡 Question word order: direct vs. embedded — 3 instances

A stand-alone question flips the subject and the verb, or adds *do*: *How do we…?*, *When will you…?* A question tucked inside a sentence keeps statement order: *…deciding what we should do next*. You flipped the embedded one and left the two direct ones unflipped, so they land as statements.

- "deciding what **should we** do next" → "deciding what **we should** do next"
- "**How we solve** that?" → "**How do we solve** that?"
- "but when **you will** have time to do this first attempt…?" → "but when **will you** have time to do this first attempt…?"

**Drill:** stand-alone → flip: *When will you…? How do we…? What should we…?* After *decide / know / ask / tell me / not sure* → no flip: *decide what we should do*, *tell me when you'll have time*.

#### 3. 🟡 No *will* after *if* / *assuming* — 2 instances

In a condition about the future, English uses the present tense; *will* belongs only in the main clause. *If you'll decide* sounds like "if you're willing to decide".

- "if in this process **you'll decide** to limit the functionality" → "if in this process **you decide** to limit the functionality"
- "assuming Pavel **will provide** everything" → "assuming Pavel **provides** everything"

**Drill:** *if / when / once / as soon as / assuming / unless* + present: *If you decide to cut something, tell us. Assuming Pavel delivers on time, when can you start?*

#### 4. 🟡 False friend (RU/UA *пока*): *so far* → *for now* — 1 instance

*So far* means "up to now" and looks back (*so far it works*). A choice that holds until something changes is *for now*. Both translate *пока*, which is why this one recurs.

- "would be the best solution for us **so far**" → "would be the best solution for us **for now**"

**Drill:** *so far* + present perfect, looking back: *So far we've had no issues.* *For now* / *for the time being*, looking ahead: *For now, let's ship one container.*

#### 5. 🟡 Over-built question — 1 instance

The ask came out as two *when* questions, with a condition wedged into the first and *when* restarted after it: about 60 words for one question. In a wrap-up, people answer the last thing they heard.

- "When do you think, assuming Pavel will provide everything he's speaking about in a timely manner, when we will be able to get to the point where we at least run our first iteration of testing. Maybe some issues arise, but when you will have time to do this first attempt of packaging it as a Helm chart?" → "**Assuming Pavel delivers on time, when could you make a first attempt at the Helm chart?**"

**Drill:** condition first, one question, stop: *"Assuming X, when can you Y?"* If you hear yourself say *when* a second time, the first question is still open: finish it instead of starting another.

#### 6. 🟡 Non-native politeness formula: *I will kindly ask you* — 1 instance

In spoken American English, *kindly* in a request sounds stiff, and with *I will* in front it sounds like an order. Make the request with *could you* or *I'd ask you to*.

- "I will **kindly ask** you to agree on that with Taras" → "**Could you** agree on that with Taras"

**Drill:** *Could you…? / Would you mind…? / I'd ask you to…* In speech, never *I kindly ask*, *I will kindly ask*, *kindly confirm*.

#### 7. 🟡 Position of *only* — 1 instance

*Only* goes right before the word it limits. *That's only my concern* means "it's just my concern, nobody else's"; you meant it was the one thing worrying you.

- "That's **only my** concern." → "That's **my only** concern."

**Drill:** *my only concern*, *the only option*, *our only blocker*; before a verb it limits the action: *we only need one container*.

#### 8. 🟡 Negative + *both* → *either* — 1 instance

With a negative, English uses *either* (or *neither*), not *both*. *We don't use anything … in both cases* can be heard as "not in both, maybe in one".

- "we don't use anything from OCI Accelerator packs provided by Oracle **in both cases**" → "we don't use anything from OCI Accelerator packs provided by Oracle **in either case**"

**Drill:** *in either case*, *neither option*, *we don't need either*; *both* only in positive sentences: *in both cases we build it ourselves*.
