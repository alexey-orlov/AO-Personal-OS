AI-Powered Customer Intelligence for Enterprise Sales 
Use Case Description
DHL, a leading logistics company, aims to improve the effectiveness and scalability of enterprise customer engagement by automating the research and preparation of account-specific insights used by sales and customer teams. Today, creating tailored customer briefings requires significant manual effort, including reviewing company filings, corporate communications, media coverage, industry reports, and regulatory or sustainability disclosures to understand each customer's strategy, priorities, and potential logistics needs.
While these briefings are valuable for structured conversations with senior stakeholders, the manual process limits coverage and slows outreach cycles. Sales teams often face a trade-off between producing a small number of high-quality briefings or covering a larger set of accounts with less detailed insights.
An automated research and insight generation approach can streamline this process by discovering relevant public information, structuring it into a coherent account context, and synthesizing key themes. This allows teams to spend less time collecting information and more time interpreting insights and preparing meaningful customer engagements.
Such capability can enable broader account coverage, more consistent meeting preparation, and better alignment between customer needs and DHL’s service offerings.
Proposed Solution & Scope
High-Level Solution Description
SoftServe proposes to develop a Proof of Concept (PoC) for AI-powered research and briefing generation system, intended to support the discovery, analysis, and synthesis of selected publicly available and internal information relevant to DHL’s enterprise customers.
The PoC is expected to include components for information ingestion, extraction of relevant content, and generation of draft customer briefings and discussion guides. It is planned to leverage NVIDIA’s AI-Q agentic framework to orchestrate selected research and generation tasks, supported by document processing pipelines capable of handling agreed document formats (e.g., PDFs, reports, web pages, presentations), which are subject for validation during the PoC.
The system will be designed to collect and analyze information from agreed data sources (including internal account data, external public sources, and limited commercial data feeds), extracting key developments such as strategic initiatives, operational priorities, and market signals.
Based on these inputs, the system will generate the following structured deliverables per account:
A draft customer briefing summarizing available company context and selected signals (e.g., strategic, operational, or market-related), based on the ingested data sources.
A discussion guide including tailored talking points, suggested questions, and recommended next steps to support customer engagement.
A structured list of sources and references, where available, to support traceability of generated outputs and facilitate validation of underlying information.

Technical Solution Overview
The solution is designed as an end-to-end pipeline for customer research and briefing generation using retrieval-augmented generation.
Data Storage & Ingestion: Materials are stored in OCI Object Storage and processed via ingestion pipelines, including OCR and text extraction (e.g., OCI Document Understanding).
Processing & Retrieval: Documents are classified, segmented, and enriched with metadata (e.g., company, source, date). Content is embedded and indexed in Oracle AI Vector Search for semantic and hybrid retrieval. Selected signals may be structured into a customer context.
Orchestration & AI: NVIDIA AI-Q orchestrates retrieval, ranking, and generation workflows. LLM inference may use OCI Generative AI or NVIDIA NIM on OCI infrastructure.
Output Generation: The solution generates draft briefings and discussion guides with references to source materials. Traceability is supported via available metadata.
Technology Stack: NVIDIA AI-Q is used for orchestration with supporting NVIDIA components where applicable. OCI services provide the cloud foundation for storage, processing, and deployment.
Document Preprocessing
OCI Document Understanding for OCR, text, and table extraction from supported document formats
OCI Object Storage for storage of source documents and processed artifacts, with versioning enabled
Supporting parsing services for HTML and other complex formats, where required
LLM / Reasoning and Generation
NVIDIA AI-Q for orchestration of retrieval, reasoning, and content generation workflows using models such as NVIDIA Nemotron 3 Super
OCI Generative AI (e.g., Cohere Command A) for content generation
NVIDIA NIM on OCI GPU infrastructure (e.g., OKE) as an alternative inference option
Retrieval
Embedding models (e.g., Cohere Embed or equivalent) for vector representation of content
Reranking models (e.g., Cohere Rerank or equivalent) for prioritization of retrieved content
Hybrid retrieval combining:
• Oracle AI Vector Search for semantic and hybrid retrieval
• OCI Search (OpenSearch) for lexical search and filtering, where required
OCI services enable combined semantic and keyword-based retrieval capabilities.
Index / Storage
Oracle Database 26AI with AI Vector Search as the primary store for content and embeddings
Hybrid retrieval combining keyword-based and vector search
APIs / Deployment

Oracle Kubernetes Engine (OKE) as the primary runtime for ingestion, orchestration, and AI services
OCI Functions and optionally OCI Streaming for asynchronous processing
OCI API Gateway for exposure of PoC APIs and service endpoints
OCI services support deployment, asynchronous execution, and API exposure within the PoC architecture
NVIDIA / GPU Components
NeMo Retriever Microservices for advanced retrieval and document processing, where required
NVIDIA NIM for inference services deployed on OCI GPU infrastructure, where applicable. OCI GPU Compute / OKE GPU node pools, for example, 2× A100 GPUs for PoC-scale deployment, subject to regional availability and tenancy limits.

This cost includes all professional services required to design, build, validate, and demonstrate the AI-powered customer research and briefing generation PoC within the agreed scope and timeline.
The cost of the package does not include OCI infrastructure setup as part of the engagement that could be requested separately. OCI Infrastructure setup includes activities such as OCI infrastructure configuration and setup, creation of OCI deployment pipelines, adopting OCI towards scaling requirements and OCI infrastructure support and troubleshooting that shall be executed by Oracle OCI team.
For details on expected production-level cost projections in the event of a full-scale deployment, please refer to the corresponding chapter.

The NVIDIA GPU portion of this cost is estimated at approximately EUR 1,860,000 per year, reflecting the GPU capacity required for sustained document ingestion, embedding generation, semantic search, and reasoning workloads.
